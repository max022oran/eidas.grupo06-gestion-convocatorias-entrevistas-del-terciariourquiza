# Requisitos del sistema

## Descripción del sistema

_Desarrollo de un sistema web que permite gestionar convocatorias, entrevistas y postulaciones, centralizando toda la información en una sola plataforma._

## Requisitos funcionales

### Módulo 1 — [Gestión de usuarios y control de acceso]

| ID | Requisito |
|----|-----------|
| RF-01 | El usuario debe poder registrarse utilizando su mail institucional. |
| RF-02 | El usuario debe poder acceder al sistema mediante sus credenciales. |
| RF-03 | El usuario debe poder cargar un CV en formato PDF desde su perfil. |
| RF-04 | El sistema debe validar que el usuario tenga un CV cargado antes de permitirle postularse a una convocatoria. |
| RF-05 | El sistema debe utilizar automáticamente el CV cargado por el usuario en cada postulación. |
| RF-06 | El sistema debe impedir que un usuario se postule más de una vez a la misma convocatoria. |

### Módulo 2 — [Docentes y Egresados]

| ID | Requisito |
|----|-----------|
| RF-07 | El usuario debe poder visualizar las convocatorias disponibles. |
| RF-08 | El usuario debe poder postularse a las convocatorias disponibles. |
| RF-09 | El sistema debe ocultar automáticamente las convocatorias que se encuentren vencidas. |
| RF-10 | El administrador debe poder crear convocatorias. |
| RF-11 | El administrador debe poder evaluar a los postulantes. |
| RF-12 | El administrador debe poder registrar entrevistas. |
| RF-13 | El sistema debe permitir redirigir al usuario hacia un sitio externo cuando corresponda. |
| RF-14 | El sistema debe mostrar los resultados al usuario. |
| RF-15 | El sistema debe mostrar estadísticas generales. |
